# Genealogy — Absorb (Wave W2)

First-class batch genealogy system of record, rewritten on Frappe from Qcadoo Advanced Genealogy semantics (NOT a code port):

- Stateful, blockable Batch objects (supersedes report-derived traceability)
- Bidirectional trees: produced-from / used-to-produce
- Batch blocking rules propagating by document type
- Supplier-batch capture on receipt

Acceptance: behaviour parity with Qcadoo characterisation tests for the trace journey (backward + forward across multi-level batches).
Source lineage: Qcadoo `mes-plugins-advanced-genealogy` (behavioural reference).
